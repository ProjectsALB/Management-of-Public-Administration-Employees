# 🇦🇱 Public Administration Employee Management System

A full-stack web application for managing employees in the public administration of Albania.
The system enables employee management, data analytics, and interactive visualizations for administrative decision-making.

## ✨ Features

- Management of local and central administration entities
- Employee records with detailed information
- Dynamic search and filtering
- Add, edit, and delete employees
- CSV import/export support
- Advanced analytics with interactive charts
- Animated visualizations for better insights
- Fully responsive UI

## 🛠 Technologies

- Node.js
- Express.js
- MongoDB + Mongoose
- HTML, CSS, JavaScript
- Chart.js
- dotenv

## ⚙️ Installation

```bash
git clone <repository-url>
cd project-folder
npm install
```

Create a `.env` file:

```
MONGO_URI=your_mongodb_connection
PORT=3000
```

Run the application:

```bash
npm start
```

Open:

```
http://localhost:3000
```

## 📊 Analytics

The system includes:
